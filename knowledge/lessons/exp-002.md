## Summary

Cross-sectional momentum (BTC/ETH/SOL 4H, lookback=6, top-1) per
pre-registered spec:
- Leakage: PASS
- Walk-forward (single 50/50): REJECTED
- Bootstrap: INCONCLUSIVE (strategy layer FAIL)

Final: **no robust evidence of predictive or trading edge.**

---

## Process lessons

### 1. Cross-sectional data construction requires explicit rules

BTC (yfinance) and ETH/SOL (Binance) did not share the same
timestamp grid. BTC had 5 gaps (44 missing 4H bars) vs Binance.

Rather than silently dropping or filling, we defined the analysis
universe as **the intersection of timestamps present in all three
assets** and recorded this as Amendment 001 in the
pre-registration, before any computation.

The rule: when data sources disagree, the resolution rule must be
pre-registered, explicit, and documented. Never silent.

### 2. Independent reconstruction can catch bugs in the audit, not just the code

The baseline portfolio audit initially reported a $10,764
discrepancy. The bug was in the audit itself (transition-bar
mark used OLD position instead of NEW). After the fix, max abs
diff was exactly 0.0.

Lesson: independent verification is a two-way discipline. It
catches implementation errors in the research code AND errors in
the verification code.

### 3. Sign-based and CI-based criteria can legitimately diverge

WFO predictive criterion (sign of mean_spread) gave FAIL.
Bootstrap predictive criterion (CI of mean_spread) gave
INCONCLUSIVE.

Both are valid. They answer different questions:
- Sign: is the point estimate positive?
- CI: is zero within sampling uncertainty?

Documenting this divergence is more honest than picking one.

### 4. High turnover changes the economics of the strategy

Baseline trade_count was 1159 (≈1 switch every 3.7 bars).
Round-trip costs at 0.05% commission + 0.02% slippage per side
dominate P&L in a top-1 rebalancing scheme.

This is a **specification property**, not a bug. The spec chose
top-1 rebalance-every-bar; the economics follow mechanically.

### 5. The bootstrap null must be named precisely

B1 in Exp 002 is a multivariate empirical-return iid bootstrap,
not a zero-drift random walk. Block length collapsed to 1 under
the ACF rule.

Naming precision matters: "random-walk null" would be misleading
here.

### 6. Baseline "strongly negative" is not the same as "strategy failed"

Baseline net_pnl = −78,027.73, Sharpe = −0.859. But B1 null
median Sharpe was −0.894 and null median net_pnl was −78,369.
The baseline is essentially at the null median.

Conclusion: the negative baseline result is consistent with what
this strategy produces on non-predictive data with the same
volatility and cost structure.

### 7. A negative WFO result should not be rescued by later layers

Bootstrap was run after WFO REJECTED. It did not, and should
not, override WFO. Each layer answers a different question and
its verdict stands.

## What transferred from Exp 001

- Clean-tree provenance discipline (same Option B pattern).
- Tag-per-layer approach.
- Negative result treated as first-class output.
- Block-length estimation via ACF rule.

## What is new in Exp 002

- **Cross-sectional data construction** rules (Amendment 001).
- **Multivariate bootstrap** preserving contemporaneous cross-asset
  dependence.
- **Two-layer verdicts** (predictive + strategy) as independent
  criteria.
- **Independent reconstruction discipline** applied to WFO splits.
- **Legitimate divergence** between sign-based and CI-based
  criteria documented.

## Open questions

1. Would a longer lookback or hysteresis reduce turnover enough to
   change the economics? (Requires new pre-registration.)
2. Is top-1 concentration the wrong design for this asset class?
   (Same constraint: new experiment.)
3. Does cross-asset predictability exist at all in 4H crypto, or
   only at higher frequencies? (New data + new hypothesis.)
4. Could the same pipeline be applied to different universes
   (e.g., top-10 L1s) without changing methodology?

## Recommendation

**Close Experiment 002.** Do not tune lookback, universe, costs,
or tiebreak in response to these results. Any such change
constitutes a new experiment and requires its own pre-registration.

The reusable asset is the **cross-sectional validation pipeline**
(causal invariants, multivariate null, two-layer verdicts).
